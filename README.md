# 놀이터 — 모바일 HTML5 게임 놀이터 (연습용)

앱스토어처럼 고르고, 모바일 게임처럼 플레이하는 HTML5 게임 플랫폼 연습 버전입니다.
빌드 도구 없이 순수 HTML/CSS/JS(ES 모듈)로 만들었고, 저장은 모두 이 기기의 `localStorage`에 합니다.

- 게임: **블록 팡팡**(8×8 블록 퍼즐), **2048 머지**
- 화면: 홈 · 게임 상세 · 플레이(풀스크린 + 채팅/음성챗 흉내) · 리뷰 쓰기 · 리워드 · 내 게임
- 모바일 세로 화면 기본, 1024px 이상에서는 사이드바 + 넓은 레이아웃
- 게임은 `<iframe sandbox="allow-scripts">` 안에서 실행되고 `sdk/playground-sdk.js`로만 플랫폼과 대화합니다
- 게임별 홈 화면 아이콘: `g/<slug>/` (PWA 매니페스트 포함)
- 포인트는 출석·플레이 시간·리뷰·친구 초대에만 지급 (게임 점수·승패와 무관)

로컬 확인: `python -m http.server 5173` 후 http://localhost:5173
